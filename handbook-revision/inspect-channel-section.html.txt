<section id="inspect-channel-permissions"><h2>Inspect a member’s channel permissions</h2><p>Use an integration token with <code>channels.permissions.read</code> and share the channel with that app. Set <code>NATTER_SERVER</code> to your HTTPS server address, <code>NATTER_TOKEN</code> to the token, and <code>NATTER_CHANNEL</code> and <code>NATTER_USER</code> to the channel and account IDs. Run <code>node inspect-channel.mjs</code> to see whether the member can rename the room and which rule determined the result.</p><p><a href="../plugin-sdk/inspect-channel.mjs" download>Download the Node.js example</a> · <a href="http-reference.html">Server HTTP reference</a></p><p>Desktop workflows can call <code>channels.permissions.list</code> or <code>channels.permissions.inspect</code> with the read capability. A write needs explicit <code>channels.permissions.write</code> consent and a user gesture. Get a fresh revision with the list action and submit it with your changes. If the revision is stale, reload and review the edits before trying again.</p><p><a href="revision/README.txt">Rebuild this handbook</a> · <a href="../plugin-sdk/handbook-permissions.patch">Download the handbook patch</a></p></section>
